## ★★ 判据与教训

### 组件原文 >>> 页面抽样

上一轮「41 用户双向零反例」得出的徽章规则，本轮被组件原文推翻了两处（门槛 >0 vs >=3、
颜色恒定 vs 三档）。**零反例只说明样本没覆盖到反例**。
判据：**只要目标是「和原生一致」，就去读它的组件原文**，
`performance.getEntriesByType("resource")` 找 chunk → curl → 读。比 CDP 探 DOM 又快又稳。

### 只按新版 DOM 写判据，会漏掉一整类页面

`.top-bar / .lside / .rside` 覆盖了所有 columba 页，**首页是旧版页**，用户菜单叫
`nav.user-nav`，一个都不匹配。判据：**写完 DOM 判据要在两代页面上各扫一遍**
（洛谷至今新旧混跑：`/record/list` 也是旧版）。

### 「移到卡片上不算离开」的快路径会跳过清理

`onOut` 里 `relatedTarget` 落在卡上就 `return`，**跳过了 `leave()`**，而 `leave()`
正是负责 `cancelOpen()` 的地方。于是路上蹭到的那个锚点留下一个待打开，300ms 后
把当前卡换掉。判据：**任何「早退」都要问一句：我跳过的那条路上原本还负责释放什么？**
（这已经是同一形状的第二次了 —— 上一次是薄壳提前 `return` 没释放 `visibility:hidden`。）

### 密排锚点之间没有空隙

练习页题号是**零垂直间距**铺开的（实测 A.bottom=193、B.top=193）。
任何「把卡片放在锚点下方 N px」的方案，**指针去卡片的路上必然横穿别的锚点**。
判据：**做 hover 交互前先量一下锚点的实际排布**，别假设锚点之间有空白。

### `Number(null) === 0` 且 `Number.isFinite(0)` 为真

已经咬过四次。只判 `isFinite` 会把「字段缺失」悄悄变成 0/Unaccepted/未关注。
必须显式排除 `null` / `undefined` / `""`。

### 类选择器的 `display` 会压过 UA 的 `[hidden]`

`.luogusp-hc-taglist{display:flex}` 让 `hidden` 属性完全失效。
**任何给了 `display` 的元素都必须自己再声明一次 `[hidden]{display:none}`。**

### 结构守卫拦得住「声明了却没人接」，行为测试拦不住

按需块的接线只要漏一处，功能就静默消失，而所有行为测试仍然全绿 ——
它们注入的是自己的 `loadBundle`。所以每个按需块都配了结构守卫。
★ 守卫自己也会「永远红不了」：剥注释必须限定行首（`/^[ \t]*\/\/[^\n]*$/gm`）。
★ 反证本身也要确认破坏真的落地了（本轮的 `cancelOpen` 反证：删掉那行 → 测试当场红 → 再还原）。

### 隐藏标签页里 rAF 不触发

扩展驱动的标签页 `visibilityState === "hidden"`，`requestAnimationFrame` 不触发。
实机审计必须让窗口与标签页处于前台。hover 卡因此改用**事件委托**，不碰 rAF。

### 搬进另一个 realm，等于换了一套宿主对象

`{ setTimeout, clearTimeout }` 简写会让 `clock.setTimeout(...)` 以 `this === clock`
调用原生方法，在页面 realm 里立刻 `TypeError: Illegal invocation`。
正确写法是包一层：`setTimeout: (fn, ms) => setTimeout(fn, ms)`。已有结构守卫扫全仓。

| 用户 | `GET /user/{uid}` + 同 header | `data = {prizes, gu, elo, dailyCounts, user}` |
| 实时评论 | `GET /article/{lid}/replies` | 受限文章也返回 200 JSON |

字段坑：

- `user.elo` / `user.eloValue` **恒为 null**，真数据在**顶层 `data.elo`**。
- `user.verified` **只在看自己时返回**，且**与页面上的 ✅ 无关**。
- `problem.tags` 是**数字 id**，必须配 `/_lfe/tags` 字典。
- `data.lastCodeAt` 是 IDE 里最后保存代码的时间，**不是**最后一次提交。
- `problem.accepted` / `.submitted` 是**按访问者算的布尔**。
- **`data.prizes[i]` 套了一层**：`{ prize: {year, contest, event, prize} }`，
  **按年份升序**（洛谷个人页也按这个顺序列）。
- **匿名访客的响应里没有 `userRelationship` / `reverseUserRelationship`**（实测），
  所以关系必须能表达「未知」。
- 匿名 curl 取 `.cn` 会先吃一发 `302 + Ws-Action: cc`（CDN cookie 挑战），
  **带 cookie jar 重试就过**（`curl -L -c jar -b jar`）。

### 受限文章的实时公共计数与真实发表时间

```
GET /user/{authorUid}/article?page={N}[&category={C}]
Header: x-lentille-request: content-only
→ data.articles = { perPage: 10, count, result: [ … ] }
```

- 文章**页面**路径被 WAF 拦，但**作者专栏列表 API 没拦**。
- `time` 是**真实发表时间**；保存站的 `createdAt` 是**入档时间**（实测差三个月）。
- `content` 截断到 128 字 → 正文仍靠保存站。
- 列表**不含** `voted` / `favored`；**不按时间排序**；`perPage` 固定 10；
  `?category=N` **有效**，`?keyword=` **无效**。
- 页面 CSP（`<meta>`）挡死页面内直连 `api.luogu.me` → 保存站必须走 `GM_xmlhttpRequest`。
  ★ 同一条 CSP 也挡死页面内 `fetch` 任何外部主机 —— 本轮想把已发布的 hover 块
  直接 import 进真页面做验证，就是这样失败的。**验证渲染请用 jsdom / 本地样张，别注页面。**
